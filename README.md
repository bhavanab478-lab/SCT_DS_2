# Task 02 - Data Cleaning and Exploratory Data Analysis on Titanic Dataset

In this task, I worked on the Titanic dataset (`train.csv`) to perform data cleaning and exploratory data analysis (EDA).

First, I imported the required Python libraries such as Pandas, Matplotlib, and Seaborn and loaded the dataset into Google Colab.

## Data Cleaning
- Checked dataset information
- Identified missing values
- Filled missing values in the Age column using mean
- Filled missing values in the Embarked column using mode
- Removed the Cabin column because it had many missing values

## Exploratory Data Analysis
I created different visualizations to understand the dataset:
- Survival count graph
- Survival based on gender
- Age distribution histogram
- Passenger class distribution
- Correlation heatmap

## What I Found
- Female passengers had a higher survival rate
- Most passengers belonged to 3rd class
- Age distribution showed passengers from different age groups
- Passenger class had an impact on survival chances
